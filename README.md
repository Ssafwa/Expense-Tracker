## WHAT IT DOES

- **Dashboard Overview:** Visual representation of total income, expenses, and current balance using interactive charts & graphs.

- **add cards:** you can add any card in here and add many of them. when  you entre the card number it automaticaly identify and change the card desing  almost to the real  card like visa,mastrcard and etc 

- **Expense Management:** Add, delete, and categorize transactions (e.g., Food, Transport, Rent, Entertainment).

- **Filtering & Search:** Filter expenses by category, date range, or transaction type.

- **Budget Limits:** Set monthly spending limits when adding the card  .

- **Export Data:** Export transaction logs into pdf.

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports, also uses a basic ui features and desings .

- **The Data storing:** basically this website not using any beckend severs, database and etc. this stores the data in localy via localstorage
