where my money went and wanted something simpler than a spreadsheet, so I 
decided to build my own instead of using an app.

## WHAT IT DOES
---------------
- Shows income vs expenses at a glance
- Keeps a transaction history
- Lets you export that history as a PDF
- Tracks spending against a limit you set (card-style UI)



  ### HOW ITS BUILD 
  ------------------
Pure HTML/CSS/JS — no framework. 
PDF export uses jsPDF + jsPDF-AutoTable — . Icons are Font Awesome.



#### RUNNING IT LOCALLY
---------------------
\`\`\`
git clone https://github.com/Ssafwa/Expense-Tracker.git
\`\`\`
Open `index.html` in your browser — no build step needed.



##### TECH STACK
----------------
- HTML, CSS, JavaScript
- Font Awesome (icons)
- jsPDF + jsPDF-AutoTable (PDF export)
