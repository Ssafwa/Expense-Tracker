# 💰 Expense Tracker # 

A simple website to track your expenses and understand where your money is going.

##  Features
____________

-  Visual overview of income vs expenses
-  Transaction history
-  Export transaction history as a PDF
- Card-style spending limit tracker

## Tech Stack
__________
  - HTML, CSS, JavaScript
- Font Awesome (icons)
- jsPDF + jsPDF-AutoTable (PDF export)

##  Getting Started
__________________

1. Clone the repo
