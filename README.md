# EXPENSE TRACKER

I built this because I kept losing track of where my money went and wanted something simpler than a spreadsheet, so I decided to build my own instead of using an app.

## Using the tracker

On your first visit, add your name and age to open the dashboard. Users under 18 can track income and expenses without linking a card; card and spending-limit features are available from age 18. Use Settings to update your profile or add a card. Add income and expenses with a date, category, and account. Profile details, spending limits, cards, transactions, and the black-or-white theme choice are saved in this browser using local storage. The card form identifies common card networks and stores only the last four digits; it does not keep the full card number. Use **Reset all data** in Settings to remove the saved profile, cards, transactions, and theme choice from this browser.

The overview and expense breakdown update from saved transactions. Choose an account to see its activity, change the period or transaction type, and sort the recent transaction list. Export creates a black-and-white PDF statement for the currently selected account.

This is a local, single-browser tracker, not a bank connection. Clearing this browser's site data also removes the saved profile, cards, and transactions.
